## 2024-05-24 - Interactive Elements Focus States
**Learning:** Interactive elements like buttons need focus states that mirror their hover states to be accessible via keyboard. Currently buttons have hover states but lack focus-visible outlines or background changes.
**Action:** Add `focus-visible:` variants alongside `hover:` variants for all buttons (Start Game, Choice Left/Right, Restart, Methodology/Target cards) to ensure screen reader and keyboard users can navigate effectively.
